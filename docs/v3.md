## Maximum useful Qlib reuse

Integration owner: awa-si/nautilus, adapter/qlib. The model core keeps its existing
NumPy/PyTorch dependency boundary. Qlib owns research orchestration around the
core; Nautilus owns market provenance and execution.

| Need | Reuse / next extension |
| --- | --- |
| Frames, slicing, preprocessing | Existing StaticDataLoader, DataHandlerLP and DatasetH boundary; fit processors on training only. |
| Dataset alignment and supervised purging | Existing adapter/qlib/dataset.py; preserve exact indices, cadence, observation schema and label maturity. |
| NHSMM training | Planned thin Qlib Model wrapper calling the public core optimizer; fit on feature sequences only, grouped by instrument and contiguous segment. |
| Regime outputs | Existing regime_features for trusted causal artifacts; planned wrapper predict returns indexed regime features with explicit provenance. |
| Experiment tracking | Qlib R/Recorder and local MLflow for configs, source/data hashes, actual updates, metrics and sealed core artifacts. |
| Regime evaluation | A small RecordTemp extension for likelihood, occupancy, duration and boundary diagnostics; reuse core diagnostics. |
| Supervised challengers | Existing real Qlib LGBModel with base versus base+NHSMM ablation; standard signal analysis applies to actual prediction scores. |
| Rolling / multiple seeds | Reuse Qlib task configuration, RollingGen and recorder collection where calendar semantics fit the declared cadence. Audit generated fold bounds before execution. |

The existing NHSMM bridge performs inference only; it does not yet implement the
planned training wrapper. The shared make_dataset currently expects labels and
maturity times. For unsupervised fits, add a feature-only path using the same Qlib
primitives rather than fabricating targets. Keep supervised label purging where
labels are genuinely consumed.

Do not apply cross-sectional IC/portfolio defaults to latent state identifiers.
Ground-truth regimes remain evaluation-only. Preserve sequence continuity,
per-instrument state, train-only fitted transforms, past-only context, fold-local
artifact provenance and explicit state alignment between independently fitted
folds. Qlib does not establish those HSMM-specific guarantees automatically.

Prefer a small declarative Qlib task and recorder over another custom experiment
scheduler or one-off training script. Keep package imports configurable and model
serialization explicit: Qlib Model's learned attributes must survive serialization;
persist and verify the core's own artifact/provenance contract as well.
