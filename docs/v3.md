# V3 model-core boundary

Active branch: `v3`. NHSMM owns model mathematics, distributions, context encoding,
initialization and optimization, causal runtime/forecasts, artifacts and reusable
health/context-validation snapshots. It depends on NumPy and PyTorch.

The [Nautilus ML stack](https://github.com/awa-si/nautilus/tree/main/adapter/qlib)
owns datasets, chronological splits, Qlib tasks, ChatGPT/RD-Agent candidate
orchestration and MLflow evidence. NautilusTrader owns execution validation.
There is no second research scheduler or Qlib compatibility layer in this core.

Legacy experiment runners, scenario configuration, their tests and historical
report trees are retired. Oracle controls remain OFF and explicitly opt-in;
their required source-checkout closure and frozen data are retained. See
[testing](testing.md) and [cleanup evidence](ml-stack-cleanup.md).

Model contracts remain in [model.md](model.md),
[hsmm-mathematical-contract.md](hsmm-mathematical-contract.md) and
[duration-tail-contract.md](duration-tail-contract.md). Independent reference,
gradient, causality, distribution and artifact tests remain the correctness gate.
No model equation, optimizer default, artifact format or frozen holdout is changed
by retiring research orchestration. Passing software tests does not establish
state recovery, convergence quality, market edge or trading qualification.

Earlier development chronology is available in
[the pinned pre-cleanup tree](https://github.com/awa-si/nhsmm/tree/c0178857da54f7099d1cb39cb76a7c5a0a6680a8).
