# V3 model-core boundary

Active branch: v3. NHSMM owns model math, distributions, context encoding,
initialization/optimization, causal runtime/forecasts, ModelConfig and artifacts.
Runtime dependencies remain NumPy and PyTorch. Numerical contracts are defined
in model.md, hsmm-mathematical-contract.md and duration-tail-contract.md.

The Nautilus ML stack owns health/context validation, research datasets and
Oracle/benchmark helpers. New namespaces: adapter.qlib.nhsmm_validation and
adapter.qlib.nhsmm_research. Frozen inputs live in tests/ml_stack/fixtures/nhsmm
in that checkout. See [extraction](ml-stack-extraction.md) and [testing](testing.md).
Oracle stays opt-in. Model math, optimizer defaults and core artifact schemas
are unchanged.
