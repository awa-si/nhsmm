## Resolved findings

### Python baseline

Resolved by raising the package/tooling contract to Python 3.12+.

- `requires-python = ">=3.12"`
- classifiers now advertise Python 3.12 and 3.13
- Black/Ruff/mypy target Python 3.12
- smoke, package-validation, and release workflows use Python 3.12
- README, contributing guidance, and repository-domain instructions are aligned to 3.12+

### Variable-length dataset state alignment

Resolved. `SequenceDataset(variable_length=True)` now wraps observations, optional context, and latent-state labels using the same sequence boundary, so `collate_fn()` receives a state sequence rather than a scalar label.

Regression coverage verifies state/context/observation length alignment and padding.

### Attention/MHA restart lifecycle

Resolved. `ContextEncoder.reset()` now clears transient cached outputs only; trainable `_attn_vector` / `_mha` state survives optimization restarts and remains part of the optimizer/state-dict contract.

Additional hardening:

- `ModelConfig.n_heads` default is now 4, compatible with the default encoder's common 32/64-dimensional output for MHA pooling;
- MHA validates `context_dim % n_heads == 0` explicitly;
- lazy attention/MHA state is created on the active context device/dtype;
- a changed encoder output dimension fails explicitly instead of silently replacing trainable pooling parameters.

### Core Polars dependency

Resolved at packaging level. Core NHSMM no longer requires Polars. `polars` moved to the optional `data` extra and `load_dataframe()` imports it lazily with a clear installation error (`nhsmm[data]`).

The existing dataframe helper remains available for compatibility; its domain-specific filename convention is still a possible future API-cleanup item.

### Configuration domain validation

Resolved for the main public numeric bounds. `ModelConfig.__post_init__()` now rejects invalid state/feature/head/duration counts, invalid optimization iteration/restart counts, invalid dropout, non-positive covariance/temperature/learning rates, and negative regularization/tolerance-style values before model construction/training.

The correctly spelled emission init mode `"random"` is now part of the declared Literal while the historical `"randome"` alias remains accepted for compatibility.

## Remaining findings

### P1 — explicit 2-D context semantics are inconsistent

`NHSMM._build_sequence_set()` and `ContextRouter.from_tensor()` do not yet expose one fully unified `[T,H]` / `[B,H]` disambiguation contract. This remains a separate API-semantic change.

### P1 — transition refinement without context has no explicit guard

Transition refinement still needs a dedicated public contract for requests made without an enabled/explicit transition context.

### P2 — base `DistributionSet` injectable factories

`nhsmm.models.base.DistributionSet.__init__()` still accepts distribution-class arguments but instantiates default classes directly. The canonical training `DistributionSet` honors these arguments.

### P2 — artifact construction mutates model mode

`build_artifact()` still prepares the supplied model for inference and therefore changes train/eval mode. A future change should define whether artifact creation is observational or intentionally mode-changing.

### P2 — context caches and logging policy

- ContextEncoder caches can retain the most recent autograd graph until replaced/reset. The lower-level `DefaultEncoder._context` cache is now detached and does not retain its forward graph.
- package-level logging policy remains configured from `config.py`.

The `nhsmm/distributions/default.py` audit is resolved. In addition to import/runtime hygiene, the distribution layer now normalizes the initial-state law, preserves absolute emission locations, keeps emission means independent of categorical temperature scaling, validates non-empty categorical support, aligns Student-t event/moment/expand semantics with PyTorch, preserves dtype/device during reinitialization, caches static transition topology, and avoids unnecessary distribution-object construction on the main batch emission path.

## DefaultEncoder audit resolved

The canonical encoder was re-audited for temporal shape, masking, streaming, cache, and runtime behavior.

Resolved:

- non-causal convolution now uses explicit asymmetric same-padding so every positive kernel size preserves sequence length, including even kernels;
- sequence masks must be right-padded; hole masks are rejected instead of being misinterpreted by `pack_padded_sequence`;
- all-false rows remain true empty rows instead of being clamped to one synthetic timestep;
- masked padding is zeroed before convolution, preventing non-causal convolution leakage from padded values into valid timesteps;
- masked recurrent outputs are zeroed consistently;
- `DefaultEncoder._context` stores a detached diagnostic cache rather than the active autograd graph.

Verification:

```text

runtime benchmark:                    PASS
```

The runtime benchmark used the canonical artifact path with 128 measured steps, 16 warmup steps, and batch size 1; bounded runtime state remained 151 tensor elements.
